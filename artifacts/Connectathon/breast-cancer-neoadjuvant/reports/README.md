# Breast cancer neoadjuvant review demonstration

CRL authors the diagnostic concepts, assessment conditions and oncology-review guidance. CEL authors the synthetic examples. CRL 6.4.2 generates CQL and FHIR definitions; the native CQL engine evaluates the supplied diagnostic bundles.

## Deliverables

- [CRL model](../src/crl/breast-cancer.crl) and [CEL examples](../src/cel/mv/breast-cancer.cel).
- Four generated CQL libraries in `src/cql`, with translated ELM JSON in `tests/verification/elm`.
- PlanDefinition, review-oriented ActivityDefinition, Libraries and ValueSets in `src/fhir`, alongside two Evidence resources, nine EvidenceVariables and the unchanged supplied fixture CodeSystem.
- [FHIR npm package](package/breast-cancer-neoadjuvant-0.0.0.tgz): 33 definitions plus an ImplementationGuide inventory. CRL embeds the local CQL attachments and preserves resource identities. Patient examples are excluded.
- Supplied source snapshots, faithful refined source, canonical anchors and provenance in their KELP entity folders.

Evidence and EvidenceVariable are not currently generated by CRL. These resources were authored manually alongside the generated definitions; direct language support will be considered. Their population, intervention, comparator, outcome, source dates and limitations remain traceable to the supplied corpus. No Measure is required for this use case.

## Decision model

The review population requires active, confirmed invasive breast cancer and documented clinical M0. Triple-negative status requires negative ER, PR and HER2 results. The tumor/node condition is clinical T1c or higher **OR** clinically positive nodes. All three assessed conditions must hold to communicate oncology-review guidance.

| Review population | Triple-negative | Tumor/node condition | Intended result |
| --- | --- | --- | --- |
| True | True | True | Oncology-review guidance |
| Any required condition is False | Any | Any | This guidance does not apply |
| No required condition is False and one is unknown | Any | Any | Applicability remains unknown |

Clinical T/N categories are supplied inputs, not inferred from tumor diameter or pathological node counts. The baseline reflects the supplied ASCO 2021 recommendation boundary. The ASCO 2022 immunotherapy update is represented in the evidence context; its distinct high-risk population is not equated with this broader review trigger. No medication order or treatment-fitness determination is generated.

## Execution results

The original 13 supplied diagnostic bundles were executed without changing their data or expectations. **91 of 104 typed expression assertions pass; 11 cases pass all eight assertions.** Exact $apply activity/error checks pass for 12 of 13 cases. The four qualifying cases each produce exactly one oncology-review CommunicationRequest.

Results and raw native responses: [verification](../tests/verification/native-current/verification.json). ## Remaining differences

- **Equivocal HER2:** the supplied unresolved code currently produces an evaluation error rather than an unknown result. This case fails all eight expression assertions and its $apply error check.
- **No indexed cancer:** five tumor-specific expressions use unanchored observations instead of remaining unknown. The diagnosis/population/applicability gates are false and no guidance is produced. Full indexed-tumor, final-status and evaluation-time selection is not established by this implementation.
- **CEL diagnostic values:** the installed emitter writes the coded values as strings. Those emitted examples do not reproduce the diagnostic fixtures. Use the unchanged supplied bundles for native execution; do not treat the CEL examples as passing diagnostic runs.
- Independent participant execution and FHIR-server storage and retrieval testing were not performed for this submission.

The implementation gaps and exact source/model identities are recorded in [implementation-gaps.json](../tests/verification/implementation-gaps.json). This package is a runnable Connectathon demonstration with the stated differences, not full conformance to every supplied case.
