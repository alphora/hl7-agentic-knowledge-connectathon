# Breast cancer neoadjuvant review demonstration

CRL authors the diagnostic concepts, assessment conditions and oncology-review guidance. CEL authors the synthetic examples. CRL 6.4.2 generates CQL and FHIR definitions; the native CQL engine evaluates the supplied diagnostic bundles.

## Deliverables

- [CRL model](../src/crl/breast-cancer.crl) and [CEL examples](../src/cel/mv/breast-cancer.cel).
- Nine generated CQL libraries in `src/cql`, with translated ELM JSON in `tests/verification/elm`.
- PlanDefinition, review-oriented ActivityDefinition, Libraries and ValueSets in `src/fhir`, alongside two Evidence resources, nine EvidenceVariables and the unchanged supplied fixture CodeSystem.
- [FHIR npm package](package/breast-cancer-neoadjuvant-0.0.0.tgz): 46 definitions plus an ImplementationGuide inventory. CRL embeds the local CQL attachments and preserves resource identities. Patient examples are excluded.
- Supplied source snapshots, faithful refined source, canonical anchors and provenance in their KELP entity folders.

Evidence and EvidenceVariable are not currently generated by CRL. These resources were authored manually alongside the generated definitions; direct language support will be considered. Their population, intervention, comparator, outcome, source dates and limitations remain traceable to the supplied corpus. No Measure is required for this use case.

## Decision model

The review population requires active, confirmed invasive breast cancer and documented clinical M0. Triple-negative status requires negative ER, PR and HER2 results. The tumor/node condition is clinical T1c or higher **OR** clinically positive nodes. The decision first checks the review population, then requires a definitive HER2 result before assessing triple-negative status and the tumor/node condition. Equivocal remains a recognized coded result and produces no guidance.

| Review population | Triple-negative | Tumor/node condition | Intended result |
| --- | --- | --- | --- |
| True | True | True | Oncology-review guidance |
| Any required condition is False | Any | Any | This guidance does not apply |
| No required condition is False and one is unknown | Any | Any | Applicability remains unknown |

Clinical T/N categories are supplied inputs, not inferred from tumor diameter or pathological node counts. The baseline reflects the supplied ASCO 2021 recommendation boundary. The ASCO 2022 immunotherapy update is represented in the evidence context; its distinct high-risk population is not equated with this broader review trigger. No medication order or treatment-fitness determination is generated.

## Execution results

The original 13 supplied diagnostic bundles were executed without changing their data or expectations. **All 13 exact guidance-output/error checks pass.** The four qualifying cases each produce exactly one oncology-review CommunicationRequest; the other nine produce none. Equivocal HER2 and absent diagnosis no longer appear as runtime blockers.

The six diagnostic concepts support typed answers and external Observation sources. CEL emits all 75 diagnostic values as CodeableConcept, preserving the authored external codes, values and dates. The actual coded value is retained, including Equivocal; there is no fabricated null Observation or null recommendation. All thirteen CEL cases produced native Questionnaire/QuestionnaireResponse pairs with zero producer failures. Their files are under `tests/results/fhir/patient`; `questionnaire-manifest-mv.json` maps them to cases. All nine generated CQL libraries translate to ELM without errors.

Results and raw native responses: [verification](../tests/verification/native-corrected/verification.json). Recheck the retained output from the artifact directory:

```powershell
python reports/tools/verify-breast-cancer-native.py src/source/challenge/use-cases/breast-cancer/test-bundles tests/verification/native-corrected
```

This checks recorded engine output rather than rerunning the engine. It also retains the separate, unchanged expression oracle: **97/104 standalone Boolean assertions pass**. Seven differ: two expressions return false for an Equivocal result rather than scalar null, and five tumor-specific expressions remain independently evaluable without a diagnosis. The decision gates those paths and returns no guidance as required. Those scalar differences remain reported; they are not evidence that CRL needs new null-output semantics. The verifier exits nonzero for these retained expression differences.

## Remaining differences

- The seven standalone expression differences described above remain. Full conformance to every expression assertion is not claimed.
- CEL's external-coded facts currently carry the generated local-input profile URL even though their resource code is external. The coded data are correct; profile conformance for these test examples is not claimed. Original supplied diagnostic bundles are also executed unchanged.
- The supplied fixtures do not establish general multi-tumor association or all status/time selection combinations.
- Independent participant execution and FHIR-server storage and retrieval testing were not performed for this submission.
